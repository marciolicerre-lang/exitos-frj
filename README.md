```
pwa-exitos/
├── index.html       → App principal

└── README.md        → Este arquivo
```

---

### 🚀 Como publicar gratuitamente (GitHub Pages)

1. **Crie uma conta** em https://github.com (grátis)
2. **Crie um repositório** novo → nome: `exitos-frj` → marque "Public"
3. **Faça upload** de todos os arquivos desta pasta
4. Vá em **Settings → Pages → Source: Deploy from branch → main → / (root)**
5. Aguarde ~1 minuto → seu app estará em:
   `https://SEU_USUARIO.github.io/exitos-frj`

6. **Compartilhe o link** via WhatsApp ou e-mail com toda a equipe!

---

### 📱 Como instalar no celular

**Android (Chrome):**
- Acesse o link → toque no banner "Instalar como App" ou
- Menu ⋮ → "Adicionar à tela inicial"

**iPhone (Safari):**
- Acesse o link no Safari
- Toque em Compartilhar (ícone de seta ↑)
- Role e toque em "Adicionar à Tela de Início"
- Toque em "Adicionar"
